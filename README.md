# Mini Hogwarts System - Digital Logic Design



**Course:** CSE 4206 : Digital Logic Design Lab at Islamic University of Technology (IUT)

## Overview

This project is a digital logic-based student management and academic information system designed around the fictional Hogwarts School of Witchcraft and Wizardry. Built entirely using combinational and sequential logic, the system handles student registration, randomized house sorting, year-wise academic statistics, and graduation tracking.

## Key Features

* **House Sorting & Registration:** Captures a student's year and randomly assigns a house using JK and D flip-flops.


* **Live Statistics:** Maintains real-time tallies of students by house and year using up-counters.


* **Access & Eligibility:** Calculates restricted library access and course eligibility (like O.W.L.s or N.E.W.T.s) based on the student's year.


* **Graduation Countdown:** Computes the years remaining until Year 7 using a subtractor and outputs to a 7-segment display.


* **Grade Display:** Converts numerical marks into letter grades (A, B, C, F).



## Core Components

* **Counters:** 74LS192 ICs for maintaining population statistics.


* **Decoders:** 74LS138 (3-to-8) and 2-to-4 decoders for driving LED indicators and eligibility lines.


* **Logic & Arithmetic:** 4008 adders/subtractors, 74LS153 multiplexers, and standard logic gates (AND, OR, NOT).
